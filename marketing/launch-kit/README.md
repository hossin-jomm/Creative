# حقيبة إطلاق صفحات Ai Creative

كل ما تحتاجه لإطلاق **فيسبوك + إنستغرام + واتساب بزنس** في يوم واحد. الصور جاهزة في مجلد [output](output).

| الملف | الاستخدام | المقاس |
|---|---|---|
| `a1-profile.jpg` | صورة الملف الشخصي (فيسبوك وإنستغرام وواتساب) | 1080×1080 |
| `a2-facebook-cover.jpg` | غلاف صفحة فيسبوك | 1640×624 |
| `b1` إلى `b5` | أغلفة Highlights في إنستغرام | 1080×1920 |
| `c1` إلى `c9` | أول 9 منشورات | 1080×1350 |

**الخط:** Tajawal (ملفاته في مجلد [fonts](fonts)، مجاني برخصة OFL). ثبّته على جهازك إذا صممت منشورات جديدة في فوتوشوب أو كانفا.

**لتعديل أي نص في التصاميم:** عدّل `make_posts.py` (للمنشورات) أو ملفات `designs/*.html`، ثم شغّل من جذر المشروع:

```bash
python marketing/launch-kit/make_posts.py
```
```bash
python marketing/launch-kit/render.py
```

## 5. نصوص المنشورات (Captions)

**الهاشتاغات** (أضف 3 إلى 5 منها فقط في كل منشور):
`#حلب` `#تسويق_إلكتروني` `#اعلانات_فيسبوك` `#اعلانات_ممولة` `#سوشال_ميديا` `#مشاريع_صغيرة` `#ميديا_باير` `#سوريا`

**1. التعريف** (`c1-intro`)
```
أهلاً بكم في Ai Creative 👋
وكالة تسويق رقمي في حلب، وشعارنا: نُكبّر مشروعك… ونكبر معك.
هدفنا بسيط: إعلانك يجب أن يجلب زبائن حقيقيين، لا مجرد إعجابات.
تابعونا، فكل أسبوع سنشارك نصائح عملية لأصحاب المشاريع 👇
#حلب #تسويق_إلكتروني #اعلانات_فيسبوك
```

**2. الخدمات** (`c2-services`)
```
3 خدمات، وهدف واحد: البيع.
1️⃣ الإعلانات الممولة: حملات هدفها الرسائل والطلبات، مع تقرير أسبوعي
2️⃣ إدارة المحتوى: خطة وتصاميم وريلز تعبّر عن مشروعك
3️⃣ التدريب: تعلّم إدارة إعلاناتك بنفسك
أيّها تحتاج أكثر؟ أخبرنا في التعليقات.
#اعلانات_ممولة #سوشال_ميديا #حلب
```

**3. طريقة العمل** (`c3-process`)
```
قبل أن نصرف دولاراً واحداً على إعلانك، نمر بـ4 خطوات:
نفهم مشروعك ← نضع خطة ← نجرّب أكثر من إعلان ← نقيس النتائج كل أسبوع.
هكذا تعرف أين ذهب كل دولار، وماذا أعاد لك.
#تسويق_إلكتروني #مشاريع_صغيرة
```

**4. الأخطاء الخمسة** (`c4-mistakes`)
```
5 أخطاء نراها كل يوم، وكل واحد منها يحرق ميزانيتك 🔥
أكثرها انتشاراً: زر "ترويج" وهدف "التفاعل" بينما تريد رسائل وطلبات.
كم خطأً منها وقعت فيه؟ 😅 احفظ المنشور وارجع إليه قبل إعلانك القادم.
#اعلانات_فيسبوك #ميديا_باير #نصائح_تسويق
```

**5. الترويج أو مدير الإعلانات** (`c5-boost-vs-ads`)
```
زر "ترويج" سهل، لكنه غالباً يجلب إعجابات فقط.
مدير الإعلانات يمنحك هدف الرسائل، واستهدافاً دقيقاً، وأرقاماً واضحة لكل دولار.
تريد زبائن؟ ابدأ من مدير الإعلانات. وإن لم تعرف من أين تبدأ، تواصل معنا.
#اعلانات_فيسبوك #اعلانات_ممولة
```

## 6. جدول النشر

**يوم الإطلاق:** انشر المنشورات 1 إلى 6 متتالية (بفارق دقائق) حتى لا يرى أول زائر صفحة فارغة.

| اليوم | المنشور | ملاحظة |
|---|---|---|
| يوم الإطلاق | 1 ← 6 | ثم ستوري للـHighlights |
| اليوم 2 | 7 (الباقة) | + ستوري |
| اليوم 3 | 8 (الورشة) | + ستوري "من المهتم؟" باستطلاع |
